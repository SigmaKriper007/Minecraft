# EXO: управление переписано с нуля

OpusVsExe, Minecraft 1.20.1 / Fabric. Затронут только слой управления экзоскелетами:
езда, камера, атака, прыжок, способности, энергия, инвентарь, сеть.
Лор (`lore.md`) соблюдён: EXO — пилотируемые боевые рамы Кодди, а не мобы;
перегрузка ядра EXO-5 всегда заканчивается окном уязвимости.

## Что было сломано и что с этим сделано

1. **Урон всегда был 8.** `ExosuitEntity` в конструкторе читал `exoTier`,
   который подкласс выставлял только ПОСЛЕ `super()`. Сейчас все цифры живут
   в `ExoTier` и передаются в базовый конструктор.
2. **Бесконечный урон.** Самописный Goal бил цель КАЖДЫЙ тик без кулдауна,
   а `attackWithRider` ставил target навсегда. Goal убран: пустая рама пассивна,
   атака идёт только от пилота и через `attackCooldown` тира.
3. **Рывки/двигатели не работали вообще.** Сервер делал `setDeltaMovement` на транспорте,
   которым управляет клиент — значение выбрасывалось. Появился пакет `exo_impulse`
   (сервер -> клиент) и `applyImpulse()`.
4. **Прыжок был только на клиенте и срабатывал каждый тик**, пока держишь пробел.
   Теперь: edge-trigger, стоимость энергии, валидация на сервере, и отдельный
   воздушный рывок для рам с двигателями (EXO-2/3/5).
5. **Камера и прицел жили отдельной жизнью.** `CameraPilotMixin` сдвигал камеру после
   всей ванильной логики (третье лицо и коллизии ломались), а `@Redirect` на
   `GameRenderer#pick` переписывал рейкаст. Вместо этого пилот теперь физически
   сидит на высоте головы рамы (`getPassengersRidingOffset`), и ванильная камера
   с ванильным прицелом сразу правильные. Два самых хрупких миксина удалены.
6. **Моб-AI боролся с пилотом** за поворот головы/тела (дёрганые повороты).
   `serverAiStep()` полностью отключён, пока внутри есть пилот.
7. **Энергия не сохранялась и не синхронизировалась**, а инвентарь рамы терялся
   при перезагрузке мира. Теперь энергия/флаги/кулдауны — synced entity data,
   всё пишется в NBT, при смерти рамы содержимое выпадает.
8. **Способности спамились** — не было ни кулдаунов, ни обратной связи,
   проверка энергии дублировалась в трёх местах, а две способности были заглушками
   с комментарием "logic would go here". Сейчас: 3 слота на раму, единый
   `tryUseAbility()` (энергия -> кулдаун -> эффект), все способности реально работают.
9. **Спешивание выкидывало на макушку 8-блочного меха** (ванильное поведение).
   Добавлен `getDismountLocationForPassenger` с поиском безопасной точки вокруг рамы.
10. **Клавиша инвентаря (E) угонялась через `isDown` + `consumeClick`** и конфликтовала
    с ванильной обработкой. Теперь отдельная клавиша R + Shift+ПКМ по раме.
11. **Левый клик полностью отключал добычу блоков** в раме. Теперь если под прицелом
    блок — работает ваниль, иначе бьёт рама. Пакеты рейт-лимитед.
12. **Пилот мог забить свою же раму**, рама получала урон от стен/кактусов,
    и могла деспавниться как обычный моб. Закрыто.
13. **ГУИ костюма ссылался на текстуру `gui/exo_inventory.png`**, которой в репо нет.
    Окно теперь рисуется кодом и показывает шкалу энергии. Текстуры не нужны.
14. **Оружие в слотах было перепутано** (`MAIN_HAND` читал слот 1) и никак не влияло
    на урон. Сейчас через `getItemBySlot/setItemSlot`, так что бонусы оружия
    применяются ванильным движком и оружие видно в руке рамы.
15. **Нет обратной связи по состоянию.** Добавлен HUD: рама, корпус, энергия,
    способности с кулдаунами в секундах.

## Шаг шагами: как применить

1. Раскопировать `src/` из архива поверх `src/` проекта (с заменой).
2. Удалить 3 файла из `УДАЛИТЬ-ЭТИ-ФАЙЛЫ.txt`.
3. Влить ключи из `lang/*.exo-additions.json` в
   `src/main/resources/assets/opusvsexe/lang/ru_ru.json` и `en_us.json`.
4. `./gradlew build` и `./gradlew runClient`.

Ничего больше править не нужно: `ModEntities`, `ModMenus`, `OpusVsExe`,
`ModItems`, рендереры и GeckoLib-модели не тронуты и остаются совместимыми
(старые методы `performAbility/performAttack/attackWithRider/rideJump` оставлены
как deprecated-заглушки).

## Управление для игрока

| Действие | Клавиша |
|---|---|
| Сесть в раму | ПКМ по раме |
| Отсеки костюма | R или Shift+ПКМ по раме |
| Выйти | Shift (ванильный спеш) |
| Шагать / стрейф | WASD |
| Ускорение (тратит энергию x3) | клавиша спринта |
| Прыжок / воздушный рывок | Пробел |
| Удар рамой | ЛКМ |
| Способности 1/2/3 | F / G / H |

## Карта способностей

| Рама | F | G | H |
|---|---|---|---|
| EXO-1 Sentinel | Удар кулаком | Стойка защиты | — |
| EXO-2 Hunter | Рывок | Режущий лазер | Маскировка |
| EXO-3 Vanguard | Двигатели | Энергощит | Ударная волна |
| EXO-4 Titan | Сейсмический топот | Укрепление | Прыжок-катапульта |
| EXO-5 Vengeance | Перегрузка ядра | Залп Возмездия | Двигатели |

## Архитектура нового управления

```
клавиша -> ExoInputHandler (edge-trigger, локальные пред-проверки)
        -> пакет (exo_ability / exo_attack / exo_jump / exo_input / exo_inventory)
        -> ModNetwork.withPilotedExo (одна точка проверки "ты вообще пилот?")
        -> ExosuitEntity (энергия, кулдаун, рейч, эффект)
        -> synced entity data -> HUD и другие игроки
        -> exo_impulse (только для того, что меняет скорость)
```

Движение осталось client-authoritative — тот же контракт, что у ванильных
лошадей и лодок. Не пытайся выставлять скорость рамы на сервере напрямую —
только через `applyImpulse()`.

## Что проверить глазами после сборки

- Сесть в EXO-5, побегать — повороты без дёрганья, камера в голове меха.
- Пробел зажать — один прыжок, не отбойный молоток.
- F на EXO-2 — рывок реально толкает (раньше не делал ничего).
- Выйти из EXO-5 — появляешься рядом на земле, а не на плече меха.
- Положить катану в слот, выйти, перезайти в мир — катана и энергия на месте.
- Зажать ЛКМ на блоке — блок всё ещё ломается.
