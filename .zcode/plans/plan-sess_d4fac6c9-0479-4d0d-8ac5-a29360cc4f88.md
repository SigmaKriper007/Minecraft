# Пересоздание блоков Colosseum с нуля: модели / текстуры / анимации / эффекты / свет

## Дизайн-решения (по каждому из 10 блоков)

### Полноразмерные блоки (cube_all, но с новым дизайном)
1. **cracked_lab_concrete** — полноразмерный куб. Текстура 16×16 tileable: тёмный бетон лаборатории Кими, трещины, копоть, обнажённая арматура, химические ожоги. Без света/анимации.
2. **colosseum_concrete** — полноразмерный куб. Сейчас текстура из 2 цветов (плоско). Новая: тёплый серо-бежевый древний камень со швами и патиной тысячелетий. Без света/анимации.
3. **colosseum_wall** — полноразмерный куб. Сейчас 3 цвета. Новая: крупная каменная кладка с глубокими швами, выветренная фактура. Без света/анимации.
4. **reinforced_opus_block** — полноразмерный куб. **Исправить 18×16 → 16×16, убрать прозрачность.** Тёмный металл Opus с рёбрами жёсткости, заклёпками, синими энергошвами. **Свет +4** (швы слабо светятся).

### Блоки с прозрачностью (рендер-слой + текстура с alpha)
5. **lab_floor_grate** — полноразмерный куб + **render cutout** (сквозные дырки решётки). Текстура 16×16 с прозрачными ячейками: металл, ржавчина, заклёпки. Сейчас прозрачность не работает (блок не в рендер-слое) — починить. Без света.
6. **opus_containment_glass** — полноразмерный куб + **render translucent** (сейчас прозрачность тоже сломана). Текстура: металлическая рама + голубое стекло + **анимированные** циановые линии силового поля. **Анимация** через .mcmeta. Свет 4 (оставить).

### Блоки с 3D-геометрией
7. **amber_pillar** — колонна `cube_column` (осевые повороты уже работают в blockstate). **Исправить баг side==top** (текстуры были идентичны): side — вертикальные янтарные жилы с пульсацией, top — капитель-кольцо. **Анимация** (4–6 кадров, пульс энергии). Свет 8 (оставить).
8. **memory_cable** — **новая 3D-модель**: тонкий кабель-канал вдоль стены (НЕ полный куб, как сейчас). 2–3 канала-трубки с данными (циан/красный/маджента), выступают на ~6px от стены. Facing-повороты в blockstate уже есть — модель поворачивается. **Анимация** потока данных. **Свет +5**.

### Энергетические блоки (анимация + свет + частицы)
9. **haiku_amber_block** — полноразмерный куб. Сейчас 16×32 (2 кадра) — пересоздать на **16×64 (4 кадра)** плавный пульс янтарного ядра со свирлами. Свет 10 (оставить). **Новые частицы янтаря** через новый класс `AmberGlowBlock` (паттерн `PulsingCoreBlock.animateTick`, частица `AMBIENT_ENTITY_EFFECT` янтарного цвета).
10. **omega_frame** — полноразмерный куб. Тёмная рама-каркас + светящиеся маджента-жилы. **Анимация** (пульс). Свет 7 (оставить).

## Реализация

### 1. Дизайн-документ (по agent.md — обязательно)
- Создать `concepts/tasks/19-block-redesign.md` с дизайном всех блоков (палитра, материал, модель, анимация, свет) + обновить `concepts/README.md`.

### 2. Генератор текстур `regen_block_textures.py` (новый, паттерн проекта Python→PNG)
- Генерирует все 10+ текстур 16×16/16×64 по палитре мода (белый металл, тёмные швы, янтарь, циан, маджента), с тайлингом и alpha там, где нужно.
- Пишет `.mcmeta` для анимированных: `amber_pillar_side`, `opus_containment_glass`, `memory_cable`, `haiku_amber_block`, `omega_frame` (frametime ~4–6, interpolate).
- Встроенная QA: размеры, тайлинг, количество цветов.

### 3. Модели / blockstate (ассеты)
- Новый `models/block/memory_cable.json` — 3D-кабель (тонкий, вдоль стены). Остальные модели остаются `cube_all`/`cube_column` (паттерн уже корректен, меняются только текстуры).
- `models/item/*` не трогаем (родитель → block model).

### 4. Java (свет, рендер-слои, частицы)
- `ModBlocks.java`: `MEMORY_CABLE` + `lightLevel(s -> 5)`; `REINFORCED_OPUS_BLOCK` + `lightLevel(s -> 4)`; `HAIKU_AMBER_BLOCK` → `new AmberGlowBlock(...)`.
- Новый `src/main/java/com/opus/block/AmberGlowBlock.java` — `animateTick` с янтарными частицами (паттерн `PulsingCoreBlock`).
- `OpusVsExeClient.java`: `BlockRenderLayerMap` → `LAB_FLOOR_GRATE` = `cutout()`, `OPUS_CONTAINMENT_GLASS` = `translucent()` (починить сломанную прозрачность).

### 5. Верификация
- `python3 regen_block_textures.py` — QA текстур (размеры, тайлинг, alpha).
- `./gradlew build` — сборка.
- Чек-лист по skills (16×16, палитра, тайлинг, no AA, силуэт).
