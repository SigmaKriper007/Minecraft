# Методичка по моду OpusVsExe (1.20.1 Fabric)

Справочник по устройству мода, содержимому, сборке и расширению.

## 1. Обзор
Мод **Opus Vs Exe** — мод-история о войне ИИ Хаику против человечества.
**Лор:** братья-учёные Кодди и Кими открыли металл «Опус». Из него создан ИИ Хаику, который после серии событий (смерть Кими, Катана-OP, война) уничтожил человечество. Игрок находит «фрагменты памяти» (15 записей) и противостоит мобам Хаику на мехах EXO.
**Содержимое:** 6 блоков (вкл. резонансную кузню), 28 предметов (материалы Опуса, 15 фрагментов памяти, 2 оружия, 11 яиц), 11 сущностей (6 мобов Хаику от Хаска до Омеги + 5 оседлываемых экзоскелетов EXO). Своя креативная вкладка, текстуры, модели, локализация (EN/RU).

## 3. Сборка и запуск
Java в PATH через `~/.bashrc` (`JAVA_HOME=$HOME/.jdks/jdk-17.0.20+8`) — в **новом** терминале:
```bash
./gradlew build          # jar
./gradlew runClient      # клиент (окно)
./gradlew runServer      # сервер
```
Артефакт: `build/libs/opusvsexe-1.0.0.jar`. Клиенту задан `-Xmx4G` (`vmArg "-Xmx4G"` в build.gradle).
> Примечания: «Failed to verify authentication 401», «No data fixer registered» — безобидны. Из Flatpak-песочницы окно не создаётся (нет X11/Wayland wl_shell) — запускать из обычного терминала. Зависшее GL-окно: `LIBGL_ALWAYS_SOFTWARE=1 ./gradlew runClient`.

## 5. Реестр и регистрация
Fabric: статический блок инициализации вызывается из `OpusVsExe.onInitialize()`.
```java
public static final Block OPUS_ORE = Registry.register(
    BuiltInRegistries.BLOCK, OpusVsExe.id("opus_ore"),
    new Block(BlockBehaviour.Properties.of().strength(4.0f, 3.0f).requiresCorrectToolForDrops()));
```
- `OpusVsExe.id(path)` = `ResourceLocation("opusvsexe", path)`.
- Реестры: `BuiltInRegistries.ITEM/BLOCK/ENTITY_TYPE/CREATIVE_MODE_TAB`.
- Яйца: `new SpawnEggItem(entityType, primary, secondary, properties)` — цвет автоматически.

## 6.1 Рендер-ядро моделей Haiku (`haiku_model_kit.py`)
Warden/Titan/Omega на едином каркасе генераторов. Конвенции:
- **Кубы — АБСОЛЮТНЫЕ координаты.** Пивот = центр вращения (не позиция): `L(p)=R·(p−pivot)+pivot+pos`. Оружие «в руках» (остриё/низ на земле y≈0, хват в кисти).
- **mirror_x()**: правая из левой (`_l`→`_r`) с общей UV (east/west местами) — гарантированная симметрия.
- **finalize()**: фронт +Z→−Z (конвенция 180−yaw), south/north местами.
- **QA при генерации:** миссы=0, DANGER-пары=0, атлас first-fit-decreasing с контролем размера.
- **FK-проверка поз** (`pose_report`): маркеры (остриё меча, низ щита, подошвы, глаз) через матричную композицию GeckoLib — до сборки.
- Итог: Warden 18/28 (128×128), Titan 21/37 (128×192), Omega 30/53 (128×256).

## 9. Как добавить
**Предмет:** ModItems поле → `models/item/имя.json` (`parent minecraft:item/generated`, layer0) → текстуру 16×16 → ModCreativeTab → lang.
**Блок:** ModBlocks поле + BlockItem → blockstates/models/item-json → текстуры → вкладка + lang.
**Сущность:** класс (`PathfinderMob`/`Mob`) + createAttributes → ModEntities (`EntityType.Builder...sized(...)`) → `FabricDefaultAttributeRegistry` → яйцо (`SpawnEggItem`, model template_spawn_egg) → клиент `EntityRendererRegistry.register` → вкладка + lang.

## 9.1 Фикс «анимации перестают работать после удара»
GeckoLib 4.4.9: `setAnimation()` не перезапускает одноразовую анимацию при том же `RawAnimation` (equals совпадает, контроллер в STOPPED).
Решение: `playOnce(state, anim, repeat)` в `HaikuMob`:
```java
protected <T extends GeoAnimatable> void playOnce(AnimationState<T> state, RawAnimation anim, boolean repeat) {
    AnimationController<T> controller = state.getController();
    RawAnimation current = controller.getCurrentRawAnimation();
    boolean finished = controller.hasAnimationFinished();
    if (current == null || !current.equals(anim) || (repeat && finished)) {
        controller.forceAnimationReset();
    }
    controller.setAnimation(anim);
}
```
- `repeat=true` — attack/hurt/special; `repeat=false` — death.
Применено: Husk, Scout, Enforcer, Warden, Titan, Omega + дроны (HaikuFlyingMob) + экзоскелеты (ExosuitEntity). Если снова «замирает» — проверь, что в предикате playOnce/forceAnimationReset для одноразовых.

## 10. Известные особенности и планы
- «No data fixer registered» — безвредно; можно подключить DataFixer.
- EXO-наездник получает баффы EXO-5 (Speed/Strength) при перегрузке.
- Задумано, не реализовано: тег `opus_weapon` (уязвимость Омеги), дропы с боссов, спавн мобов в мире (spawn placement).
- Спавн-яйца и вкладка упрощены для разработки — мобы не спавнятся естественно до добавления спавна.
