# Задача 3 — Haiku-2 Scout (колёсный разведчик, WALL-E)

## Референсы (MASTER_PLAN §5.3, §6)
- Роль: маленький колёсный разведчик (~0.8 блока), «быстрый, слабый». Stats: hitbox 0.55×0.8, HP 15, урон 2, скорость выше средней.
- ВАЖНО: убрать FloatGoal и FLYING_SPEED из Haiku2Entity — Scout НАЗЕМНЫЙ; наземные цели/блуждание (WaterAvoidingRandomStroll).
- WALL-E: кубический корпус-ящик, ДВА больших колеса с грунтозацепами, глаза-бинокль (2 янтарных орба) на штыре, руки-щипцы (манипуляторы), антенна-спинка, грязь/износ.

## Дизайн-решение
**Силуэт:** компактный юнит ~15px (≈0.94 блока при scale 1); в ScoutRenderer база `BASE_HEIGHT=0.9375` (не 1.875).
- корпус: брюхо (5.6×1.3) + шасси-ящик (7×7.5×6) + крыша кабины (6×1.8); передняя «морда»-плита (face_plate): янтарная визор-щель, 2 сервис-порта, вент-щели, грязь внизу; бока — вент-жалюзи с износом;
- колёса: 2 больших (9px, tread) на осях X (вращение в move: 0→1440°/с);
- глаза-бинокль: штырь + голова 4.2×1.3 + янтарная бровь + 2 орба;
- щипцы: 2 манипулятора снаружи корпуса (±3.7, чтобы не з-фрайтить стенки): arm+pincer;
- антенна-спинка с янтарным наконечником (качается в idle);
- износ: царапины, грязь по нижним кромкам.

**Ориентация:** фронт −Z (mirror_z, конвенция Husk).

**Скелет (8 костей):** scout_root → body (брюхо, шасси, крыша), wheel_l, wheel_r, eye_stalk (штырь, бинокль, бровь, 2 глаза), claw_l (arm+pincer), claw_r, antenna.

**Анимации:** idle — боб, наклон глаз-штыря (yaw/pitch), покачивание антенны, подёргивание щипцов, «моргание» (scale штыря 1→0.45→1); move — вращение колёс (X, 1440°/с), крен, виляние антенны; attack — щипцы сжимаются (z-ротация ±26°), корпус выпад вперёд (position z −0.9), взгляд штыря; death — заваливается набок (z→85°), колёса докручиваются, антенна обвисает.

**Игра:** HAIKU_2→ScoutRenderer; hitbox 0.55×0.8; HP 15, урон 2, скорость 0.3, follow 45; цели игрок+голем; FloatGoal и FLYING_SPEED удалены.

## QA
1. JSON без `"parent": null`; root без parent; анимации только на существующие кости.
2. Копланарность: 4 пары — только внутренние стыки (брюхо⇄шасси, шасси⇄крыша, тыл arm⇄pincer); без з-фрайта.
3. Глаза-бинокль и визор-щель смотрят на −Z.
4. Яйцо → маленький колёсный робот ~0.8: колёса крутятся, щипцы при атаке, заваливается при смерти.
5. Build зелёный.
