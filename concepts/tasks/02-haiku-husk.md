# Задача 2 — Haiku 1.5 Husk (человекоподобный пехотинец)

## Референсы (лор)
- «Haiku 1.5 Husk — Человекоподобный (по лору)». Хаику не летают (наземные).
- Лор из кода: самый слабый и распространённый моб, ближний бой, низкий урон, иногда «глючит» (повторяет анимации/звуки).

## Дизайн-решение (зафиксировано)
**Роль:** лёгкая человекоподобная пехота массового производства.
**Силуэт:** антропоморфный в 29px (≈1.81 блока): голова-шлем с гребнем → кираса с плечевыми накладками → руки с предплечьями-излучателями и клешнями → ноги с наколенниками и тяжёлыми ступнями. Классические пропорции солдата.

**Семейный язык (STYLE ANCHOR — перенести, НЕ копируя тарелку):**
- бело-серый металл + тёмные швы + ЕДИНСТВЕННЫЙ цветовой акцент — янтарь (глаз, ядро, порты);
- орб-кольцо на груди (ядро), янтарная щель-визор вместо глаз;
- «глаза-дырочки» не делаем — визор-полоса (мотив «печати»);
- заклёпки/швы/сервопанели — текстурами, минимум кубов.

**«Глюк» (лор):** левая антенна-сенсор дёргается в idle (анимация), правая потушена (тёмный кончик — сгоревший сенсор). Единственная фоновая асимметрия.

**Пропорции (px):** ступни 0..1.5 → голени 0.5..5.5 → наколенники 4.75..6.25 → бёдра 5.5..10.5 → пояс 10.5..12.5 → кираса 11..20 → шея 19.5..21 → голова 21..29. Ширина: корпус 7px, плечи ±7px (широкая идентичность пехотинца), ноги ±4px, ступни с выносом.

**Анимации (geometry.husk):** idle — боб корпуса, микроповорот головы, дёрганье левой антенны (sin t·7.3), пульс ядра (scale 1↔1.12), редкое подёргивание плеча; walk — противоход рук-ног, спина вперёд 12°, лёгкий боб; attack — подъём+отвод правой → выпад предплечья-излучателя → отдача → возврат (0.6с, anticipation→strike→recovery); death — падение вперёд вокруг поясницы (0.8с).

**Скелет (23 кости):** root → spine → {chest (кираса+пояс), neck, core_orb, лев/прав плечо→предплечье→кисть, голова (голова+челюсть+гребень+визор+вент), антенна_левая/правая}, ноги: лев/прав бедро→голень→ступня (+наколенники).

**Игра:** hitbox 0.6×1.8, HP 20, урон 3 — БЕЗ изменений боевых параметров; заменяется только внешность (HuskRenderer вместо Placeholder).
