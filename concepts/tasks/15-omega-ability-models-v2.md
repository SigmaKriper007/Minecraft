# Задача 15 — Пересоздание 3D-моделей способностей Омеги (v2)

## Контекст
4 атаки босса имеют 3D-сущности-эффекты: кольцевая волна, дуговой слэш, небесный лазер, снаряд-шрапнель. Их модели/анимации/текстуры пересоздаются с нуля. Размеры атак и механика НЕ меняются — только визуал (больше костей, детальнее текстуры, сложнее анимации).
Конвенция GeckoLib: геометрия в юнитах ×16 от блоков, рендеры scale(1.0F), шрапнель scale(3.0F).

## 1. Кольцевая волна (omega_ring)
Тема: расходящееся кольцо янтарной энергии, разогретая плазма, бегущая волна.
**Кости:** `root` (0 кубов) + `seg_0..seg_31` (3 куба каждый: корпус-оболочка, горячий фронт, ядро-свечение). Радиус 204 блока (3264 юнита). Сегмент 1 (корпус) 896×8×110 юнитов (56×0.5×7 блоков), стиль `glowband`; Сегмент 2 (горячий фронт) 884×6×84, яркая полоса A→P→f; Сегмент 3 (ядро) 864×4×64, P→f, `paint_core` с прозрачностью. Кубы центрированы в пивоте сегмента.
**Текстура 64×64:** горизонтальные полосы тёмный металл (S) → янтарная (A→P→f) → ядро (f→W). Художники `paint_glowband`, `paint_orb`, `paint_core`.
**Анимации:** `pulse` (loop 0.8с) — 32-фазный каскад: каждый seg_N scale 1.0→1.25→1.0 (сдвиг 2.5% фазы); `hold` (loop ∞) — мягкая пульсация 1.0→1.04→1.0 + rotation.y ±0.5°. Сущность играет `hold`.

## 2. Дуговой взмах (omega_slash)
Тема: серповидный энергетический клинок, янтарная плазма с белым ядром.
**Кости:** `root` + `seg_0..seg_7` (2 куба каждый: тело клинка + горячая кромка). Радиус 138 блоков (2208), сектор 110°. Тело заужено к краям: центр 14 блоков (224 юнита), края 6 (96); центральный 896×224×160, крайние 896×96×160, linear taper. Кромка по внешней дуге 884×8×80, A→P→f. Углы: seg_0 −48.125°, seg_7 +48.125° (шаг ~13.75°).
**Текстура:** тело A→P с прожилками (f) и тёмной окантовкой; кромка W→f. `paint_glowband`, `paint_hazard`.
**Анимации:** `spawn` (0.5с) — каскад зажигания от центра (seg_0/1 0→1.0 на 0–0.2с, остальные с задержкой ~0.05с, EaseOutBack); `hold` (loop 1.0с) — rotation.y ±1°, пульс 1.0→1.03→1.0; `out` (0.4с) — scale→0, easeIn.

## 3. Небесный лазер (omega_sky_laser)
Тема: октагон-телеграф, вращающаяся звезда предупреждения, удар колонны чистой энергии.
**Кости (6):** `root` (9: 8 октагон-сегментов + центр-диск + hazard-кольцо), `star` (4 луча, вращается), `pillar` (внешняя оболочка 60×80×60), `pillar_core` (внутреннее ядро 30×80×30), `pillar_fire` (яркий центр 12×80×12, f→W), `impact_ring` (кольцо у основания, 0.5с burst).
- Октагон: 8 сегментов 81.4×11.84×81.4, pivot на окружности; центр-диск 118.4×8.88×118.4; hazard-куб 100×10×100; звезда 4 куба S=360, pivot [0,8.88,0]; колонна 960×1280×960 / core 480×1280×480 / fire 192×1280×192; impact_ring тор 960×8×960, при strike scale 0→1.5→0 за 0.5с.
**Текстура:** октагон — янтарный металл + hazard; звезда A→P→f; колонна слоями (S→e / A→P→f / f→W).
**Анимации:** `preview` (loop 1.0с) — звезда rotation.y 0→360, сегменты мигают (0.8→1.2→0.8), ядро пульсирует, pillar скрыты (scale 0); `strike` (4.0с, ×2 скорость) — звезда гаснет (0–0.3с), pillar растёт easeOutBack (0→1.0 за 0.25с), fire синхронно, impact_ring вспышка (0→0.5с, 0→1.5→0), core 0→1.0→1.2→0.9.

## 4. Шрапнель (omega_shrapnel)
Тема: гранёный янтарный орб с вращающимся гало-кольцом и трёхсегментным хвостом.
**Кости (5):** `root` (4: гранёный орб 0.72³, core 0.56³ P→f, glow 0.84³ inflate 0.1, outer 0.9³ inflate 0.15 с прозрачностью), `halo` (кольцо 0.12×0.12×0.84), `tail_1` (0.36³×0.6), `tail_2` (0.28³×0.7), `tail_3` (0.18³×0.8) — расширяются к концу (size.xz > size.z/3).
**Текстура:** орб — янтарная матрица + core; хвост тёмный металл → янтарь к кончику.
**Анимации:** `flight` (loop 0.5с) — орб rotation.y 0→360, halo 0→−180 (противовращение), ядро 1.0→1.08→1.0, хвост хлыст (tail_1 z ±8°, tail_2 ±12°, tail_3 ±16°); `impact` (0.3с) — root scale 1.0→2.0→0.2, halo 1.0→3.0→0.1, хвост→0.1 + яркая частица + звук.
