# MASTER PLAN — вся линейка машин Haiku

Единый документ: лор-фундамент, визуальный язык (STYLE ANCHOR), палитра, дизайн-концепт и промт ДЛЯ КАЖДОЙ модели, порядок задач. Обновляется перед каждой задачей.

## 1. Лор-фундамент (зафиксировано)
- **Haiku** — род боевых машин (автономных роботов) в войне против фракции EXO (игрок).
- Энергия машин — **янтарная** (amber): реакторы, глаза, орбы, лучи. Это их «кровь».
- Все машины с одной производственной линии → единый визуальный язык, но каждая — отдельный юнит со своим силуэтом и ролью (НЕ клоны одного корпуса).
- Цветовое семейство (закреплено в текстурах): бело-светлый металл + тёмные швы + янтарное свечение. Шаблон свечения: dark-amber → amber → bright-amber → white-core.
- Haiku — **наземные** существа (кроме Дронов — воздушная ветвь).
- Омега — финальный босс: **древний** робот (потрёпанный, потускневший, устаревший, но величественный).

## 2. Визуальный язык семьи (STYLE ANCHOR — модель «тарелки», уходит дронам)
| Свойство | Значение |
|---|---|
| силуэт | обтекаемые формы, «челюсть-стрела»/скошенные носы, кольца, сегментированный хвост-оболочка |
| материалы | белый/светлый металл (W/F/g), тёмный металл швов (S/e), янтарные орбы |
| свечение | орб-глаз, орб-ядро в груди/корпусе, орб на конце хвоста — шаблон d→A→P→f→W |
| мотивы | кольцо вокруг корпуса, скошенная голова-печать, стыковочные швы, сервопанели |
| контраст | белое тело + чёрно-серые уплотнения + янтарь как единственный акцент |
| отличия между тирами | износ растёт с тиром: Husk почти новый, Omega ржаво-древний |

НЕ копировать форму тарелки для наземных — переносить **язык** (палитру, материалы, свечение, мехлогику).

Силуэт: обтекаемый корпус-«бабочка» с кольцом, скошенная голова-челюсть, хвост-оболочка 4 сегмента + янтарный орб, два «ручья»-крыла. Левитация, покачивание (idle), крен (drift). Drone+ — только размер/мощность. Промт: tasks/01. Статус: МОДЕЛЬ ГОТОВА, сущности созданы.

### 5.2 Haiku 1.5 Husk — человекоподобный пехотинец
Промт: человекоподобная пехотная машина ~1.75 (hitbox 0.6×1.75). Антропоморфный силуэт: голова-шлем со скошенной «печатью» (мотив семьи, НЕ тарелка), кираса с наплечниками, руки с излучателями в предплечьях, ноги с сервоприводами. Янтарный орб-глаз (один, слегка мигающий — «глюки» Husk по лору) или два визора. Янтарное ядро в груди. Корпус чуть ношеный. Анимации: idle (дрожание сервоприводов + мигание глаза), walk, attack (удар предплечьем-излучателем), hurt. Силуэт читается с 20+ блоков. Файлы: geo/entity/husk.geo.json, textures/entity/husk.png (128×128, C-UP|A, pz), husk.animation.json. → ВЫПОЛНЕНО.

### 5.3 Haiku-2 Scout — колёсный разведчик (WALL-E)
