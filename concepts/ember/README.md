# Ember concepts

Автономная параллельная линия — дубликат Fire Biom (предметы + мобы) с новыми текстурами, моделями и анимациями. Источники истины:
- `DESIGN.md` — визуальная ДНК, дизайн брони (рога/крылья), анимации, мобы, техника;
- `PLAN.md` — этапы реализации и приёмка.

Ветка не использует лор Fire Biom; код изолирован под `com.opus.ember.*`.
