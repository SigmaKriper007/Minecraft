# Sovereign of Four Veins — redesign (Diablo-style demon)

> Переработка модели `fire_demon` («Владыка Четырёх Жил») по референсу diablo_minecraft. Полностью новый гео/анимации/текстура; логика босса и реестр не меняются. Пути те же: `geo/fire/demon.geo.json`, `animations/fire/demon.animation.json`, `textures/fire/entity/demon.png`.

## 0. Референс (что должно читаться)
- Краснокожий человекоподобный демон, мускулистый, неглубокий таз, широкие плечи.
- **ДВЕ пары крыльев**: верхняя большая, нижняя малая. Структура: тёмная кость-плечо → предплечье → 2–3 спицы-пальца, кончики — чёрные крюки; между спицами тёмно-красная мембрана с рваным (фестончатым) нижним краем.
- **Два больших сегментированных рога**, наружу-вверх, тёмные (почти чёрные с коричневым), кольцевые наросты.
- Светящиеся красные глаза, мрачный череповидный лик, острые уши.
- Тёмная рваная **набедренная повязка** (полосы).
- Руки/ноги: красная кожа, тёмные когти на кистях/ступнях (в тёмных «копытах» с 2–3 когтями).
- **Длинный сегментированный хвост** (костяная цепь), вниз-вбок, наконечник-стрела с двумя бородками.

## 2. Скелет (geo)
```
root
├─ pelvis { loin (повязка), tail_0..tail_8 → tail_tip (стрела+2 бородки), thigh_l/r → shin_l/r → foot_l/r }
├─ torso { chest_core (тлеющее сердце — пульс в sealed), upper_arm_l/r → forearm_l/r → hand_l/r (3 когтя)
│          └─ weapon_anchor → trident (серповидный, только на TRIDENT),
│   wing_l/r (верхн.: плечо→предплечье→finger_a/b/c → memb_1..3 + крючья),
│   wing_low_l/r (нижн. пара: плечо→предплечье→finger_a/b → мембраны + крючья),
│   neck → head (череп, челюсть, уши, глаза, брови) → horn_l/r (base→mid→tip) }
└─ ice_front/back/left/right/top/floor (печать, скрыта после пробуждения)
```
Совместимость: `root, pelvis, torso, chest_core, neck, head, jaw, upper_arm_l/r, forearm_l/r, hand_l/r, thigh_l/r, shin_l/r, foot_l/r, wing_l/r, wing_forearm_l/r, wing_finger_a/b(_c)_l/r, weapon_anchor, trident, ice_*` сохраняются; добавляются `wing_low_*`, `horn_*`, `tail_*`, `loin`, `memb_*`.

## 4. Анимации (имена сохраняются: sealed/idle/walk/awaken/melee/toss/fireball/aura/trident/summon/death)
- sealed: chest_core пульс; голова опущена; кончик хвоста микроволна.
- idle: дыхание торса; верхние крылья ±4°, нижние — контрапункт ±3°; кивок головы; волна хвоста (tail_7/8 ±8°); повязка качается.
- walk: бёдра ±25° с противоходом рук; боб; крылья следуют с запаздыванием.
- awaken: крылья раскрываются (−18°→−70°→−40° обе пары); челюсть открывается; подъём из приседа.
- melee: замах правой −75° → удар 35°; торс скручивается.
- toss: обе руки вверх (−65°→40°), торс наклоняется.
- fireball: правая −105° (ладонь вверх), кисть разворачивается 45°.
- aura: крылья распахнуты (±80°/±60°), руки в стороны (±75°).
- trident: weapon_anchor −90° (подъём) → +40° (бросок); рука −120°→30°.
- summon: торс приседает (−2y)/(+1y); руки вверх (−45°).
- death: root падает 90°, y −5 z +6; крылья складываются (30°→35°).

## 5. План
1. `gen_sovereign_model.py` → geo + анимации + текстура (перезапись 3 файлов).
2. Java-совместимость: трезубец скрыт ВСЕГДА, кроме замаха TRIDENT (правка `FireDemonModel.setCustomAnimations`).
3. QA: имена костей (анимация ⊆ гео), валидный JSON/PNG, зоны текстуры.
4. `./gradlew build`.
